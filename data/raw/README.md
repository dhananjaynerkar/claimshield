# Dataset

`FraudDataset.csv` is the local dataset used by the final notebook. It contains 15,420 vehicle insurance claim records and the `FraudFound_P` target.

The original project folder did not include upstream provenance or a redistribution license. Confirm publication rights before making this CSV public. If redistribution is not permitted, add the CSV to `.gitignore` and provide it locally through an authorized source instead.
