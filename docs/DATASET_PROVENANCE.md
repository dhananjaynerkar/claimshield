# ClaimShield dataset provenance

**Status: NOT CLEARED FOR PUBLIC REDISTRIBUTION**

The repository contains data/raw/FraudDataset.csv. The current repository documentation records the following facts:

- The dataset is used by the notebook and contains 15,420 records.
- The upstream source, license, and redistribution permission were not present in the checked-out project materials.
- The repository owner must confirm publication rights before redistributing the CSV.

This document records the open gate; it does not grant permission and does not make the dataset safe to redistribute.

## Required owner confirmation

Before keeping the CSV in a public repository, record:

1. Upstream dataset name and canonical source URL.
2. License or written redistribution permission.
3. Whether derived artifacts and notebook outputs may also be shared.
4. Any required attribution or usage restriction.
5. The date and person who confirmed the permission.

## If permission is unavailable

- Remove the CSV from the public repository and its history using an approved repository-cleanup procedure.
- Keep the data local and document an authorized download or placement step.
- Keep the project documentation explicit that the model cannot be reproduced without the authorized input.

Do not upload a replacement dataset or personal/real insurance claims to resolve this gate.
